HOW DOES A QUEUE WORK?

A queue is a linear data structure where the first element added is the first element removed. Imagine people lining up at a counter: whoever arrives first is served first.

Main Operations

  • Enqueue: Add a new element to the rear (back) of the queue.
  • Dequeue: Remove the element at the front of the queue.
  • Peek: View the front element without removing it.
  • Display: View all elements from front to rear.

STEP-BY-STEP EXAMPLE

Suppose we perform these operations in order:

  1. Enqueue 10 — the queue contains 10.
  2. Enqueue 20 — 20 joins the rear: 10, 20.
  3. Enqueue 30 — 30 joins the rear: 10, 20, 30.
  4. Peek — returns 10 without changing the queue.
  5. Dequeue — removes 10, so 20 becomes the new front.
